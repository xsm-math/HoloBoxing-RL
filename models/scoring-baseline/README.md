# 主动得分对战基线

[holoboxing.onnx](holoboxing.onnx) 可作为 HoloBoxing 本地评测中的对手，供防守策略开发和攻防对比使用。此版本已完成标准起点、交换红蓝方的完整 60 秒测试，导出日期为 2026-11-27。

| 项目 | 内容 |
| --- | --- |
| 输入 | float32 `obs[1,1097]` |
| 输出 | float32 `target_pose[1,225]` |
| 策略接口 | `holomotion_v2_boxing_obs1097_target_pose225_v1` |
| 模型大小 | 30,758 字节 |
| SHA-256 | `785a16a3c81abeecd8e4abd842ffeb8fd0b417658af3c81a42ab4c66f2b4acd6` |
| 文件依赖 | 权重均在 ONNX 内，无外部权重文件 |

模型从比赛回放中拟合双腕周期动作，并结合对手位置、接近距离、转向、姿态平衡和跟踪滞后补偿输出未来五个时刻的五点位姿。参考回放使用红方第 20–30 秒的 500 个控制帧，拟合频率为 2.843 Hz。模型使用动作拟合与参数搜索，未使用 PPO。

## 对战结果

比分始终按“本模型∶对手”显示。比赛使用 v12 计分规则、标准起点和指定下层控制器。本地执行环境为 Windows 适配的 v12 运行代码、MuJoCo-Warp 和 RTX 4060 8GB。完整原始回放留在训练工作区，仓库提供哈希和结果摘要。 [结果摘要](results.json)

| 对手 | 本模型执红 | 本模型执蓝 |
| --- | ---: | ---: |
| 队友提交模型 | 77∶0 | 78∶0 |
| 最早防御版 | 17∶0 | 2∶0 |
| 队友对测防御版 | 5∶0 | 9∶0 |
| 首次回放更新防御版 | 30∶0 | 18∶0 |
| 侧移脱困防御版 | 0∶0 | 30∶0 |
| 绕行护胸防御版 | 29∶0 | 15∶0 |

使用交付文件重新执红对阵队友模型，复测结果为 77∶0。上述比赛均打满 60 秒，双方均无倒地。我方得分均为有效命中。队友模型 SHA-256 为 `477984270e13a1ede29e09ba4c2053ad45d3ad7963c2238d2f654e2d348dd331`。

本地完整推理链校验通过，RTX 4060 上平均耗时 9.647953 ms。此数值仅对应本地显卡和运行环境，官方云端资格尚未验证。后续模型和更强进攻型对手的评测见 [联赛最终交付模型](../league-final/README.md)。本模型的侧移对手测试存在一场平局，也存在边位差异。

模型加载、标准对局与回放方式可按官方 v12 教程操作。 [官方本地评测教程](https://github.com/HorizonRobotics/HoloMotion/blob/master/holoboxing/README.zh-CN.md)

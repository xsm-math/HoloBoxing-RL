## 数据与失败机制

分析了三组用户提供的真实MP4和HDF5。实际解码查看0–50秒概览及2–5秒密集抽帧，并结合姿态、接触冲量和计分事件；未宣称逐帧观看完整视频。三场蓝方均为上述基线，完整3000控制帧。

| 外部录像比分（红:蓝） | 主要证据 |
| --- | --- |
| 28:2 | 红方22次躯干、6次头部有效命中；基线朝向误差中位约36°，最长38.86秒无分。 |
| 39:2 | 红方36次躯干、3次头部，左手26、右手13；10次相邻命中间隔不超过0.6秒。大幅双腕轨迹与连贯攻击得到状态支持；蓝方前50秒多次严重侧背对。 |
| 138:1 | 红方骨盆中位0.473米、最低0.402米，膝弯约103–107°且无倒地；131次torso、7次pelvis计分（本版规则将pelvis归入躯干语义）。命中高度中位0.771米，冲量中位5.505N·s，间隔中位0.335秒。双方朝向较正，不能只归咎于转向。 |

原始输入哈希记录在JSON中。元数据 `official=false`、`development_only=true`，不作官方资格证明。没有取得三名红方原始ONNX，**从回放学习的参考轨迹及代理模型不等于恢复原策略**。

## 实际训练、控制设计与迭代

本轮是**有限维轨迹/几何拟合、手工反馈设计和物理对战校准**，没有训练端到端PPO或AMP，也没有把实测姿态当作已知的原始高层动作标签。CPU拟合可并行，GPU完整物理对战串行。

1. **组合拳分支**：从39:2红方5–40秒的1327帧、46周期拟合双腕三谐波参考，42个位置系数、12次Huber迭代；频率约1.724Hz。结合收拳、工作距离、伸展期前送和下移拳路。后段运动重建来自同一场录像，周期相位可使用相邻峰值，不能当作独立策略验证。大幅摆臂版本曾退化，最终body专家对基线15:5、10:4，但对低位B3为0:39、0:31：它保持朝向却没有适应对手高度。
2. **低重心分支**：从138:1的40–50秒、488帧、26周期拟合两谐波参考，并协调双腕、双踝、骨盆姿态及P/H坐标变换；频率约2.632Hz。随后利用一次物理轨迹中221帧做有界相位执行误差校准，修正倾身目标和平衡反馈的冲突，再加入伸展期有限前送。B3对基线4:0、5:0，后半程会停攻；对body专家31:0、39:0，则有持续有效命中。第四版仍未解决后半程停攻，未替换B3。
3. **反击分支**：三个回放双方共6个视图，前40秒12000原始训练视图，经四方向旋转增强为48000视图，拟合39参数胸位岭回归；动作残差仍由人工设计。初版退化；后版在普通站姿条件与基线完全等价，低位反制也未稳定获益，因此未纳入交付模型。该分支另做了集成模型的坐标、旋转和门控审计。
4. **交付策略**：冻结body与B3两个专家。通过自身踝点和对方骨盆相对位移估计对手绝对骨盆高度；低位权重为 `clip((0.60-h)/0.06, 0, 1)`。高度至少0.60米选body，不高于0.54米选B3，区间内混合位置并重新正交化旋转轴。这是手工选择器，没有新增训练；它识别姿态高度，不能识别拳法身份。

900个CPU姿态检查通过；真实回放估高平均绝对误差约1厘米，但依赖至少一个踝点接近地面。对基线直接复测为 **15:5、16:3**，不进入下述共同池总数。红场与body专家的物理轨迹完全相同，不能增加独立证据；蓝场仅3帧部分混合就改变后续轨迹，不能将该比分解释为持续低位专家优势。

## 接口、计分与时延

冻结官方HoloMotion 2.0 `model_10500` 下层；Windows适配v12、MuJoCo-Warp、RTX4060 8GB，控制50Hz、物理200Hz。计分版本为 `hands_only_normal_impulse20ms_5Ns_cooldown200ms_fall030_ko1000_v6`：指定头/躯干部位的手击在20ms内累计法向冲量达到5N·s，同手200ms冷却。未修改下层、计分器或物理核心；资源与模型哈希见JSON。

单选手高低层链路预热10次、计时100次；包含观测、推理、解码、缓存更新，不含物理步进及输出修复。

| --- | ---: | ---: | --- |
| 动态壁纸运行 | 9.491 | 12.410 | 否 |

模型与官方计时代码在这两组测量间未改变，壁纸测后恢复。工具的本地接口PASS不等于时延PASS；保留超时测量，不只选最快结果。**官方RTX5090资格尚未验证**，不能用固定倍率换算时延。

ONNX格式、大小、接口、有限输出及旋转检查通过；主评测32条、补充4条记录重新核对原始回放、计分事件、初态、模型/资源身份和零输出修复。此次重命名保持模型SHA-256，未新增训练或物理对战。

## 局限与材料范围

- 主评测仍有7场至少20秒未得分，最长49.42秒；基线为11场、最长60秒。零得分场由4降到0，后30秒累计得分76增到125，但持续进攻仍未完全解决。
- 低位B3对基线的4:0、5:0远未重现原138:1的压制；它主要从攻击站姿目标的记录学习，对低位目标也可能缺乏有效攻击。战胜代理不能写成战胜原始线上对手。
- 高度选择可能产生较大目标跳变；有限测试中的零倒地不保证任意初态或未知对手的稳定性。颜色、接触时序和数值差异仍会改变轨迹。
- 本次公开模型、训练测试说明、38条结果摘要及哈希；原始MP4/HDF5、完整物理日志和本轮训练/校准脚本归档保留在本地交付材料。本目录不是能够从零重训的完整数据与代码包。

## 校验与资料依据

下载后可用PowerShell `Get-FileHash ./model3.onnx -Algorithm SHA256`，或Linux/macOS `sha256sum model3.onnx`，与校验文件核对。对战加载遵循[官方HoloMotion教程](https://github.com/HorizonRobotics/HoloMotion/tree/master/holoboxing)；输入输出约定未因文件名改变。

- [England Boxing教练手册，组合拳p.89](https://www.englandboxing.org/wp-content/uploads/2022/03/EB_Boxing-Coaching-Handbook-Part-1_v8-002.pdf)：距离、组合衔接、平衡与收拳，映射为双腕相位参考、回收及距离控制。
- [AIBA教练手册，p.44、49–50、60–65](https://www.iba.sport/wp-content/uploads/2018/07/AIBA-Coach-Regulations-Manual_WEB.pdf)：屈膝攻击躯干与回拳防护。机器人仅直接控制骨盆、双腕、双踝，不声称直接控制肘部或头部。
- [Boxing Canada手册，§5.11/5.14/5.15](https://boxingcanada.org/wp-content/uploads/2025/01/Instruction-Beginners-Reference-Manual-EN.pdf)：防守应保留回击能力，作为反击分支的机制依据。
- [Arimoto等，1984，迭代学习控制](https://onlinelibrary.wiley.com/doi/abs/10.1002/rob.4620010203)：借鉴执行误差修正参考的思想，本轮只有一次有界校准，不声称满足对抗接触下的收敛条件。
- [Residual Reinforcement Learning原论文](https://arxiv.org/abs/1812.03201)、[AMP原论文项目](https://xbpeng.github.io/projects/AMP/)用于研究分解与风格学习思路，本轮未实施这些论文的RL训练。
